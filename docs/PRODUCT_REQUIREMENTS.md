# Product Requirements

## Product goal

Provide a local-first academic literature agent that turns a research topic into a traceable, reviewable set of papers without binding the user to one discipline.

## Primary workflow

1. Create a research task.
2. Enter the topic, optional research questions, language policy, date range, target count, and data sources.
3. Start a run.
4. Inspect the Agent state and result count.
5. Review each paper and mark read, save, background, or ignore.
6. Download legal open-access PDFs and send selected papers to Zotero.

## Product boundaries

The first product release is single-user, local-first, and Windows-oriented. It does not bypass paywalls, scrape authenticated databases, generate a complete thesis chapter, or make unsupported claims about a paper.

## Language policy

Tasks support Chinese, English, and bilingual retrieval. Original metadata remains unchanged. The default analysis language is Chinese.
