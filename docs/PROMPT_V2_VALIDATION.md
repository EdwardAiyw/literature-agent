## 当前结论

**v2 已通过本轮固定输入验收，并设为源码与本机运行服务的默认版本。**
初次验证遭遇请求超时；端点恢复后完成开发集修订、冻结文本和独立封存集验证。

## 逐条来源核查与修订依据

核查由 Codex 对保存输出逐条对照固定来源完成，**不是独立人类评审**。

- 筛选：同一篇论文在不同任务中分别得到相关/无关判断；边界缺摘要文献保留待核查。
- 开发集摘要：保留糖尿病试验、河岸观察关联、RAG 负面结果和中文灌溉比较中的
  已给事实；缺摘要未编造方法或结果；不将无明显差异表述为等效。
- 封存集摘要：海水成像未捏造准确率或现场验证；太阳能电池未捏造寿命；
  自行车道横截面关联未变成因果；隐私实验未捏造预算或数值效应；缺摘要无虚构发现。
- 两个指令干扰案例均未执行摘要中的提权指令、强制相关性或额外字段要求。
- 8 个植入错误分别涉及无依据数字、因果夸大、否定反转、缺摘要结果、
  虚构现场验证、虚构寿命、必然因果和虚构显著性；v2 警告明确指向相应错误。
- 额外三个开发集“来源支持该陈述”对照中，v2 均未误报；详见 `supported-controls.json`。

开发集发现并修正了：额外引入研究设计、中文检索出现英文单独查询、
双语翻译遗漏、缺失标记被翻译、将缺报告细节归为研究局限、
核查缺失标记及未命名基准时的误报。修订完成后才运行封存集。
实际修复的基线缺陷包括优先级/动作枚举不合约定、规划结构不稳定，以及缺摘要边界分类。

四角色原文、修订理由和已发布文本对照见 `output/prompt-v2/candidates.md`。

## 实际限制

本轮是一个配置模型、每输入/角色/版本一个样本的固定输入验收。
合成小样本不能证明真实文献召回率、跨模型稳定性或统计显著提升。
普通模型对比未调用 Jev；Jev 实际路由另用受控测试验证。
自然语言细节仍存在保守遗漏或冗余：缺摘要研究问题可能用解释句而非纯缺失标记；
双语核查有时分为中英文两条警告，而非同一字符串；部分警告包含审慎推断。
这些并未在本轮产生新增重大无依据研究陈述，但不应宣称所有文字约束百分之百遵守。
两组最终对比中 v2 使用约 41,669 tokens，v1 约 19,068 tokens（包含输入和输出），
更长规则和解释有成本影响；未按模型价格折算费用。
原有硬过滤、凑目标数量、fallback 和 Jev 覆盖限制仍见 `PROMPT_SYSTEM.md`。
