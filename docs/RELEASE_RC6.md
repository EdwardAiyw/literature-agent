# Literature Agent 0.3.0-rc.6

RC6 将 RC5 之后的源码功能纳入 Windows 安装包，并支持同版本 Linux 服务器部署。此版本仍为 prerelease；完整人工安装、覆盖升级、计划任务、恢复及卸载验收尚未全部完成。

## 主要变化

- 每日订阅在模型筛选前合并跨来源论文身份，并排除本订阅已成功推送的论文。迁移回填独立推送历史，失败邮件、测试邮件和 no-send 不消耗论文。
- 支持截止到运行当天或固定日期，保存运行配置快照；旧订阅保留固定日期策略。篇数为可配置上限，不足时按实际数量发送，无新增时发送说明。
- 支持任务/订阅自动导入指定已有 Zotero 集合，提供批次进度、失败重试和重启恢复；每日邮件可附标识符 TXT。
- 默认查询可核实的官网 JIF，展示年份与来源；支持 JCR CSV，查询失败不影响推送。预印本/会议论文通常不适用，出版商覆盖有限。
- 支持单用户 Linux Docker 常驻调度、SSH 网页管理、订阅编辑和受文件权限保护的持久密钥。
- 保留 Prompt v2、逐篇 Zotero 导入、相关性门槛、来源限流诊断、备份和可选 LocalJev。主动 LocalJev 筛选未通过质量门槛，现有服务器保留 Shadow。

## 安装与升级

从同一 Release 下载 `Literature-Agent-0.3.0-rc.6-Windows-x64.exe` 和 `SHA256SUMS.txt`，核对校验值。完成活动任务并备份后退出旧程序，再覆盖安装。用户数据和 Windows 凭据默认保留；数据库自动迁移，回退应恢复匹配的迁移前备份。

服务器更新与回退见 [运维手册](SERVER_DEPLOYMENT.md)。历史 RC5 标签和安装包不变。程序内稳定版更新检查可能看不到候选版，请使用 RC6 的直接下载链接。

## 验证范围

发布工作流必须通过后端全量测试、前端构建、完整 Edge 回归与打包程序检查。打包检查包含版本、数据库隔离、迁移版本/推送历史表、Prompt v2、JIF 默认值、Zotero 配置、日期策略切换及转换无投递副作用。真实文献补发和 Zotero 导入验收见 [去重记录](DAILY_DEDUPLICATION.md)。

本版本不提供多用户登录、PDF 下载或严格恰好一次的 SMTP 投递保证。
