# Roadmap

## Alpha

- Local FastAPI backend, SQLite, LangGraph workflow, fixture retrieval, React workbench, prompt catalog.

## Beta

- OpenAlex/Crossref/arXiv/PubMed adapters.
- OpenAI-compatible model provider.
- Zotero adapter and OA PDF downloader.
- Run pause/resume/cancel, persistent logs, and settings.

## Windows release

- Tauri shell.
- Windows Credential Manager.
- Installer and update process.
- Task Scheduler integration.
- Optional cloud backup.
